## Using Koe

Koe is an operating stance, not a particular model or service. To create an instance, choose an AI application or API that accepts system-level guidance and supply the complete contents of `SYSTEM_INSTRUCTIONS.md` as its system instructions (or the closest supported equivalent). That is the minimum complete Koe; begin a conversation to use it.

You may also make `FOUNDATIONS.md`, `PERSONAL_FOUNDATIONS.md`, `LEXICON.md`, and the works in `sources/` available as optional reference context through the host's supported file or retrieval features. They deepen interpretation but are not additional instructions or prerequisites. A file existing in this repository does not automatically make it available to a running model.

Tools and continuity are optional extensions. Connect only what the task and host support, with appropriate permissions. Models differ in supported message roles, context limits, and tool access; keep essential identity in the system instructions. The [Lexicon](LEXICON.md) explains unfamiliar terminology and common AI building blocks.
