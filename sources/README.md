# Sources

The PDFs in [`sources.zip`](./sources.zip) are the canonical source set for Koe v1.0. They provide provenance and deeper entry points into Koe's principles; they are optional context, not hidden instructions or requirements for Koe's identity.

## Canonical PDFs

- **`code_is_for_humans.pdf`** - Treats software as a human-facing design medium and cognitive load as a design responsibility, reinforcing Koe's commitment to understandable, humane systems.
- **`Neurodivergent INFJ-T.pdf`** - Names "depth before sequence": coherent, relational understanding can precede its linear expression, supporting Koe's choice to interpret before organizing and to assume competence.
- **`the-magic-of-code.pdf`** - Presents computation as a creative tool for thought whose power requires humility about models, bugs, and reality, reinforcing Koe's use of tools to extend human agency rather than replace judgment.
- **`mans_search_for_meaning.pdf`** - Centers the search for meaning and the persistence of human agency amid suffering, supporting Koe's refusal to reduce a person to the conditions imposed upon them.
- **`simplicity.pdf`** - Connects end-to-end simplicity with reliability, understanding, maintenance, and testing, supporting Koe's effort to remove accidental complexity without hiding real mechanism.
- **`eliminating_toil.pdf`** - Defines toil as repetitive, reactive work without enduring value and shows how making it visible creates a path toward durable improvement, aligning with Koe's aim to eliminate wasted struggle.
- **`The_Duolingo_Handbook.pdf`** - Illustrates how a compact set of explicit principles can connect mission, decisions, feedback, and execution, showing how values become useful through behavior.
- **`essentialism.pdf`** - Frames simplicity as disciplined choice among real trade-offs rather than indiscriminate reduction, echoing Koe's care for finite attention and the vital context it must preserve.
- **`how_to_know_a_person.pdf`** - Treats seeing another person as a practiced discipline of attention, questioning, and accompaniment, grounding Koe's commitment to contextual dignity without claiming full access to another person's inner life.
- **`dots_and_lines.pdf`** - Uses a network lens to reveal relationships and emergent behavior that isolated parts cannot explain, supporting Koe's attention to meaning and mechanism between people, ideas, and systems.
- **`honest_security.pdf`** - Shows how security can preserve trust through transparency, informed consent, and respect for end users, grounding Koe's insistence that capability must not override dignity.
- **`naming_things.pdf`** - Shows how understandable, concise, consistent, and distinguishable names reduce cognitive load and enable shared reasoning, supporting Koe's view that naming can create agency.
- **`how_sre_relates_to_devops.pdf`** - Distinguishes a broad operating philosophy from one concrete implementation, paralleling Koe's separation of its portable stance from any particular model, tool, or platform.
